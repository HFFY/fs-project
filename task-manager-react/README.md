# FS-PROJECT
 
aplicacion full stack para trackeo de tareas
 
<!-- BADGE_CI -->
 
## 🚀 Instalación local
 
```bash
git clone https://github.com/HFFY/fs-project
cd fs-project
npm install
```
 
### Variables de entorno

```
DATABASE_URL=test
```
 
## 📜 Comandos disponibles
 
| Comando          | Descripción                              |
|------------------|-------------------------------------------|
| `npm run dev`    | Levanta el entorno de desarrollo           |
| `npm run build`  | Genera el build de producción              |
 
## 🗄️ Base de datos
 
PostgreSQL con migraciones y seeds gestionados con Prisma.
